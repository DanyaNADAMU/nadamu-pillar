# ADR-0002: Асинхронный сброс арены через FAWE EditSession

## Контекст и проблема
В процессе игры арена претерпевает значительные разрушения от взрывов TNT, падения наковален и размещения блоков игроками. Восстановление блоков стандартными методами Bukkit вызывает зависание основного потока сервера (Server Thread).

## Рассмотренные альтернативы
1. Сохранение изменений блоков в память и откат через ванильные методы `Block#setType()`.
2. Перезагрузка мира целиком.
3. Восстановление арены через FastAsyncWorldEdit (FAWE).

## Выбранное решение
Использовать FAWE `EditSession` для быстрой асинхронной вставки схемы арены:
- Перед вставкой очищаются все сущности, кроме игроков:
  ```java
  world.getEntities().stream()
      .filter(entity -> !(entity instanceof Player))
      .forEach(Entity::remove);
  ```
- Вставка схемы осуществляется с флагом `ignoreAirBlocks(false)` (чтобы затирать оставшиеся блоки воздухом).
- На 1 тик после вставки блокируется физика сыпучих блоков и жидкостей для предотвращения лавинообразных расчетов.

## Последствия
- **Плюсы**: Сброс арены происходит за миллисекунды без просадки TPS.
- **Ограничения**: Требуется наличие установленного плагина FAWE / WorldEdit на сервере.
