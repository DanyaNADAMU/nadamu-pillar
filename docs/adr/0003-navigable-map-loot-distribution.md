# ADR-0003: Взвешенный рандомизатор лута через префиксные суммы

## Контекст и проблема
В мини-игре игрокам регулярно выдается случайный лут с разными вероятностями (весами). Линейный перебор элементов плоского списка с весами при частой выборке и большом числе предметов требует $O(N)$ операций на каждую выдачу.

## Рассмотренные альтернативы
1. Построение плоского массива, где каждый элемент повторяется пропорционально целочисленному весу (ограничение: высокое потребление памяти при дробных весах).
2. Линейный поиск по списку $O(N)$.
3. Использование структуры данных на основе префиксных сумм (Cumulative Weight Distribution).

## Выбранное решение
Использовать `java.util.NavigableMap<Double, LootItem>`, где:
- Ключ — накопленный вес (нарастающий итог $\sum_{i=1}^{k} w_i$).
- Суммарный вес $W = \sum w_i$.
- Случайное вещественное число $r \in [0, W)$.
- Поиск элемента выполняется через `map.ceilingEntry(r)` за $O(\log N)$.

## Последствия
- **Плюсы**: Высокая производительность $O(\log N)$, поддержка дробных весов, детерминированная точность распределения.
- **Ограничения**: Необходимость пересчета дерева при динамическом изменении весов.
