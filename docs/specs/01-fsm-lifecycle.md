# Спецификация 1: FSM Lifecycle

## 1. Базовый интерфейс состояния
```java
package space.nadamu.nadamupillar.fsm;

public interface GameState {
    void onEnter();
    void onTick(int currentTick);
    void onExit();
    boolean canPvp();
    boolean canBreakBlocks();
    String getName();
}
```

## 2. Матрица состояний

### `WAITING` (Ожидание)
- **Условие входа**: Старт плагина или завершение предыдущего раунда.
- **Поведение**:
  - Игроки находятся в режиме `GameMode.SPECTATOR`.
  - Свободно летают над центром арены (или точкой обзора).
  - Столбы игроков отсутствуют (чистая бездна или декоративный центр арены).
  - PvP и ломание блоков запрещены (`canPvp = false`, `canBreakBlocks = false`).
- **Переход**: При количестве игроков $\ge \text{min-players}$ (по умолчанию 2) или по админ-команде `/pillars start` переход в `STARTING`.

### `STARTING` (Быстрый обратный отсчет — 5 секунд)
- **Условие входа**: Достигнут порог игроков.
- **Длительность**: 5 секунд (100 тиков).
- **Поведение**:
  - Игроки все еще в `GameMode.SPECTATOR`, могут наблюдать за центром арены.
  - Звуки тиков и визуальный отсчет: 5.. 4.. 3.. 2.. 1.. (Title / ActionBar через MiniMessage).
  - Если во время отсчета игрок отключается и количество игроков падает ниже `min-players` -> отсчет отменяется, возврат в `WAITING`.
- **Переход**: По истечении 5 секунд переход в `ACTIVE`.

### `ACTIVE` (Генерация N столбов и битва)
- **Условие входа**: Завершение 5-секундного отсчета.
- **Поведение**:
  1. Фиксируется точный список подключенных игроков ($N$).
  2. Генератор арены рассчитывает геометрию под $N$ участников и мгновенно строит ровно $N$ столбов вокруг центра.
  3. Игроки переводятся в `GameMode.SURVIVAL`, очищается инвентарь, снимаются эффекты.
  4. Асинхронная телепортация игроков по одному на каждую вершину столба (`player.teleportAsync()`).
  5. Разрешение PvP (`canPvp = true`) и взаимодействия с блоками (`canBreakBlocks = true`).
  6. Запуск планировщика лута ($T_{\text{loot}}$) и катастроф ($T_{\text{disaster}}$).
- **Переход**: Если число оставшихся живых игроков $\le 1$, переход в `ENDING`.

### `ENDING` (Празднование на руинах — 7 секунд)
- **Условие входа**: В живых остался 1 или 0 игроков.
- **Длительность**: 7 секунд (140 тиков).
- **Поведение**:
  - Арена **не стирается сразу**!
  - Победитель остается стоять на своем столбе среди руин, получает фанфары, праздничный Title, салюты и неуязвимость.
  - Выбывшие игроки в спектаторах летают вокруг арены, осматривая поле боя.
  - В чат выводится статистика матча.
- **Переход**: По истечении 7 секунд — очистка арены за 10 мс через FAWE и возврат в `WAITING`.
