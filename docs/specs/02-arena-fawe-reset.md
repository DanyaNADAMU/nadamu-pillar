# Спецификация 2: Arena Generation & Reset

## 1. Назначение
Сервис отвечает за процедурное построение арены под $N$ участников при старте матча и безопасную очистку блоков/сущностей после фазы празднования.

## 2. Процедурная геометрия (CubeCraft Style)
При старте матча известно точное количество игроков $N$.
1. **Расчет радиуса арены**:
   Для комфортной дистанции между соседними игроками $D$ (по умолчанию 14 блоков):
   $$R = \frac{D}{2 \cdot \sin(\pi / N)}$$
   (Для 2 игроков $R = 8.0$, для 4 игроков $R \approx 10.0$, для 8 игроков $R \approx 18.0$).

2. **Координаты столбов**:
   Для каждого игрока $i \in [0, N-1]$:
   $$\alpha_i = \frac{2\pi \cdot i}{N}$$
   $$X_i = X_{\text{center}} + R \cdot \cos(\alpha_i), \quad Z_i = Z_{\text{center}} + R \cdot \sin(\alpha_i)$$

3. **Центральная платформа (CubeCraft Center)**:
   - Располагается в $(X_{\text{center}}, Y_{\text{center}}, Z_{\text{center}})$.
   - Генерирует диск или кольцо радиуса $R_{\text{center}}$ (по умолчанию 5-6 блоков).
   - Использует случайную мозаику из двух/трех блоков (например, `60%light_blue_concrete,40%cyan_concrete`).

4. **Столбы игроков**:
   - Вершина: платформа $3 \times 3$ на заданной высоте $Y$.
   - Поверхность: случайное распределение блоков палитры.
   - Тело столба: спуск вниз на $H$ блоков.
   - Нижний слой: бедроковый сердечник.

## 3. Очистка и сброс (Reset)
1. **Безопасное удаление сущностей**:
   ```java
   world.getEntities().stream()
       .filter(entity -> !(entity instanceof Player))
       .forEach(Entity::remove);
   ```
2. **Очистка блоков**:
   Удаление всех построенных/разрушенных блоков в кубе арены через замену воздухом с `fastmode: true`.
