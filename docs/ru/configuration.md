# Справочник по настройке плагина

В этом документе подробно описаны все файлы конфигурации, параметры карт, система лута и команды плагина **Pillars of Fortune** (`nadamu-pillar`).

---

## 1. Основной конфиг: `plugins/NadamuPillar/config.yml`

Файл `config.yml` управляет основными таймингами матча, порогами игроков и глобальными свойствами мира:

```yaml
# ==========================================================
# Конфигурация Pillars of Fortune (nadamu-pillar)
# ==========================================================

game:
  # Минимальное количество игроков для запуска отсчета STARTING.
  min-players: 2

  # Длительность обратного отсчета в секундах перед началом боя.
  countdown-seconds: 5

  # Время празднования победителя на руинах поля боя в секундах.
  # В это время арена еще не очищается, спектаторы летают вокруг победителя.
  celebration-seconds: 7

  # Интервал (в секундах) между выдачей случайного лута живым игрокам.
  loot-interval-seconds: 5

  # Интервал (в секундах) между запуском случайных катастроф на арене.
  disaster-interval-seconds: 30

  # Длительность предупреждающего титра (Title) перед ударом катастрофы (в секундах).
  disaster-warning-seconds: 5

  # Автоматический запуск матча при достижении min-players.
  # При вызове /pillars stop этот флаг переключается в false.
  auto-start: true

  # Идентификатор карты по умолчанию при старте сервера.
  default-map: "classic_bedrock"

world:
  # Название пустотного мира, где проводятся матчи.
  name: "world"

  # Высота (Y), ниже которой падение игрока перехватывается как смертельное.
  # Для Minecraft 1.18+ граница мира опущена до -64, поэтому дефолт установлен на -70.
  # Игрок моментально переводится в спектатора без экрана смерти.
  void-death-y: -70
```

## 2. Конфигурация карт: `plugins/NadamuPillar/maps/*.yml`

Файлы карт определяют геометрию столбов, паттерны блоков и список разрешенных катастроф.
В плагин встроены две карты:
* `classic_bedrock.yml` — классические столбы $1 \times 1$ из коренной породы (`BEDROCK`) без центрального острова.
* `classic_neon.yml` — неоновая арена со столбами $3 \times 3$ и центральным островом.

### Пример карты `classic_bedrock.yml` ($1 \times 1$, без центра):
```yaml
name: "<gray><bold>Classic Bedrock</bold></gray>"
world: "world"

geometry:
  # Высота (Y), на которой располагаются верхние площадки столбов игроков
  y-level: 100
  # Расстояние в блоках по дуге окружности между соседними столбами игроков
  distance-between-players: 14.0

pillars:
  # Размер площадки столба (1 означает 1x1 блок)
  size: 1
  # Глубина столба вниз от поверхности
  depth: 5
  # Паттерн блоков поверхности, тела и основания
  surface: "BEDROCK"
  body: "BEDROCK"
  bottom: "BEDROCK"

center:
  # Центральный остров отключен
  enabled: false

features:
  # Список катастроф, разрешенных на данной карте
  allowed-disasters:
    - "meteor_shower"
    - "anvil_rain"
    - "ghast_assault"
    - "wind_charge_storm"
    - "levitation_wave"
```

### Синтаксис паттернов блоков (`BlockPatternParser`):
Парсер поддерживает гибкий процентный синтаксис (в стиле WorldEdit):
- Одиночный материал: `"BEDROCK"` или `"STONE"`.
- Процентная смесь двух блоков: `"60%light_blue_concrete,40%cyan_concrete"`.
- Смесь нескольких блоков: `"50%magenta_concrete,30%purple_concrete,20%crying_obsidian"`.

## 3. Конфигурация лута: `plugins/NadamuPillar/loot.yml`

Система лута основана на принципе **Политики по умолчанию (`defaults`)** и **Переопределений (`items`)**:

```yaml
defaults:
  # true  = динамический лут (выпадают все предметы Minecraft, за исключением items с enabled: false)
  # false = белый список (выпадают только предметы из items с явным enabled: true)
  enabled: true
  weight: 10.0
  stack-1: 1          # количество для предметов со стаком 1 (щит, ведро, оружие)
  stack-16:           # диапазон для предметов со стаком 16 (жемчуг, снежки, яйца)
    min: 1
    max: 2
  stack-64:           # диапазон для предметов со стаком 64 (блоки, стрелы, еда)
    min: 1
    max: 2

items:
  # 1. Запрещенные предметы (нельзя поставить или использовать в Выживании)
  COMMAND_BLOCK:
    enabled: false
  BARRIER:
    enabled: false
  ENDER_DRAGON_SPAWN_EGG:
    enabled: false

  # 2. Переопределения веса и количества
  SNOWBALL:
    weight: 25.0
    min: 2
    max: 3
  SHIELD:
    weight: 20.0
  MACE:
    weight: 18.0
  BREEZE_ROD:
    weight: 15.0
    max: 1
  HAY_BLOCK:
    weight: 20.0
    min: 1
    max: 2
```

### Логика работы:
* **Наследование полей:** если у предмета в секции `items` не указан `weight` или `min`/`max`, они берутся из `defaults` (с учетом `maxStackSize` предмета).
* **При `defaults.enabled: false`:** выпадают только те предметы, у которых в `items` явно указано `enabled: true`.

## 4. Катастрофы арены

| Идентификатор | Название | Описание действия |
|---|---|---|
| `meteor_shower` | Метеоритный дождь | Спавнит падающие огненные шары и подожженный динамит над полем боя. |
| `anvil_rain` | Дождь из наковален | Сбрасывает наковальни над головами игроков. |
| `ghast_assault` | Атака гастов | Спавнит агрессивных гастов, атакующих выживших взрывными фаерболами. |
| `wind_charge_storm` | Шторм ветровых зарядов | Запускает высокоскоростные заряды бриза, сдувающие игроков со столбов. |
| `levitation_wave` | Волна левитации | Накладывает эффект левитации, сменяющийся плавным падением. |

## 5. Команды администратора

Для выполнения команд требуется право `nadamupillar.admin`:

- `/pillars start [сек]` — запустить матч с обратным отсчетом (по умолчанию берется из конфига).
- `/pillars stop` — принудительно остановить текущую игру, очистить арену, перевести игроков в спектаторов и **выключить автостарт**.
- `/pillars autostart <on|off|toggle>` — включить, выключить или переключить автоматический запуск матчей при наборе игроков.
- `/pillars status` — вывести текущий статус игры, состояние автостарта, фазу FSM и список живых игроков.
- `/pillars forcenext` — немедленно пропустить обратный отсчет (в фазе `STARTING`) или запустить проверку условий победы (в фазе `ACTIVE`).
