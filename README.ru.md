# Pillars of Fortune (`nadamu-pillar`)

Высокопроизводительный динамичный плагин мини-игры для серверов Minecraft на базе **Paper 1.21.4** и **Java 21**.

В **Pillars of Fortune** («Столбы Удачи») игроки появляются на вершинах изолированных парящих столбов над бесконечной бездной. Каждые несколько секунд участники получают случайный взвешенный лут и сталкиваются с природными и магическими катастрофами (метеоритный дождь, падающие наковальни, атака гастов, шторм ветровых зарядов, волна левитации). Цель игры — выжить, сбросить соперников в бездну и остаться последним выжившим.

---

## Ключевые особенности

- **Надежный FSM жизненный цикл**: Детерминированная стейт-машина (`WAITING` -> `STARTING` -> `ACTIVE` -> `ENDING`) без динамической перерегистрации слушателей событий.
- **Динамическая процедурная генерация арен**: Автоматический расчет позиций и построение $N$ столбов для игроков и центрального острова в стиле CubeCraft с использованием FastAsyncWorldEdit (FAWE) в нулевой тик матча.
- **Движок взвешенного лута**: Бинарный поиск по префиксным суммам (`WeightedLootTable`) с алгоритмической сложностью $O(\log N)$, поддержкой произвольных весов, зачарований и кастомных названий.
- **Движок катастроф**: Расширяемый фреймворк катастроф (метеориты, наковальни, гасты, ветровые заряды, левитация).
- **Мгновенный перехват смертельного урона и бездны**: Моментальный переход в режим наблюдателя при падении ниже $Y = -10$ или получении смертельного урона без ванильного экрана смерти (`You Died!`).
- **Одномировая архитектура**: Плагин спроектирован под работу в единственном пустотном мире (`world`), исключая накладные расходы на мультимиры и рассинхронизацию.
- **Современный Adventure API**: 100% форматирование через MiniMessage без устаревшего `ChatColor`.

---

## Системные требования

- **Java**: 21 (LTS) или выше (Amazon Corretto, Eclipse Temurin).
- **Серверная платформа**: [Paper](https://papermc.io/) 1.20.5+ / 1.21.4.
- **Зависимости**: [FastAsyncWorldEdit (FAWE)](https://intellectualsites.github.io/download/fawe.html) для Paper 1.21.

---

## Быстрый старт и установка

1. Поместите плагин **FastAsyncWorldEdit (FAWE)** в папку `plugins/` вашего сервера.
2. Скачайте последнюю версию `NadamuPillar-1.0.0.jar` со страницы [GitHub Releases](https://github.com/DanyaNADAMU/nadamu-pillar/releases) (или соберите из исходников) и поместите в папку `plugins/`.
3. Настройте сервер на использование **пустотного мира (Void World)** и отключите Ад и Край для максимальной производительности.
4. Запустите сервер.

> [!TIP]
> Подробные пошаговые инструкции по настройке пустотного мира, отключению лишних измерений и тонкой настройке параметров читайте в [Руководстве по установке (RU)](docs/ru/installation.md) или [Installation & Setup Guide (EN)](docs/en/installation.md).

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/pillars start` | Принудительно запускает отсчет или матч | `nadamupillar.admin` |
| `/pillars stop` | Сбрасывает матч в состояние `WAITING` | `nadamupillar.admin` |
| `/pillars status` | Показывает текущее состояние игры и живых игроков | `nadamupillar.admin` |
| `/pillars forcenext` | Принудительно вызывает следующую случайную катастрофу | `nadamupillar.admin` |

## Сборка из исходников

```bash
# Клонировать репозиторий
git clone https://github.com/DanyaNADAMU/nadamu-pillar.git
cd nadamu-pillar

# Проверка и запуск тестов
./gradlew check
./gradlew test

# Сборка готового плагина (опционально -Pversion=X.Y.Z, по умолчанию 1.0-SNAPSHOT)
./gradlew build -Pversion=1.0.0
```
Готовый JAR-файл будет находиться по пути `build/libs/NadamuPillar-1.0.0.jar`.
